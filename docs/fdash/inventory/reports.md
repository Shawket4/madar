## How to read a row

`| id | behaviour | API call | gate | i18n keys | web source |`

- **id**: `REP-<PAGE>-NNN`. Page codes: `ALL` area-wide, `OPS` operations, `FIN` financial, `INV` inventory, `LEG` legal, `LOY` loyalty, `BUN` bundles, `STF` staff discipline, `SPL` staff drinks, `TIL` tills, `BAS` Basira.
- **API call**: method + path + operationId (the operationId is the `dashboard_api` method name).
  - `{scopeBranchId}` is the selected branch, or the all-branches sentinel `00000000-0000-0000-0000-000000000000` when "All branches" is selected (`data/scope/use-scope.ts:19`). `{branchId}` means the selected branch only.
  - `from`/`to` are the scope's day-bounded ISO instants in the active timezone. They are never null; the default preset is `30d`.
  - "local dates" means `YYYY-MM-DD` of the instant in the active timezone (`cairoParts`). `none` means no call.
- **gate**: the client capability (any-of unless noted), the module, or `none` (shown to whoever reaches the page). The server gate is in brackets when I checked it. For example, `[orders read]` is the legacy `check_permission("orders","read")`, which maps to `orders.read`.
- **i18n keys**: `key` "English as in en.json". Every key exists in en.json AND ar.json (section 12). Where the source's inline default differs from en.json, the user sees the en.json words, and those are quoted here.
- **web source**: `file:line`, relative to `MadarDashboard/src/`, using these abbreviations:

## 11. Formatting rules and values computed in the browser

### 11.1 Money (`fmt:60-132`)
- On the wire, money is an integer number of piastres (minor units). `fmtMoney` divides by 100 and always shows 2 decimals, grouped en-US with Latin digits.
- English shape: "EGP 1,234.50". Negative: "−EGP 50.00", using a true minus U+2212. Zero is never signed.
- Arabic shape: the figure is LTR-isolated (U+2066 … U+2069), then a space, then the Arabic currency label (EGP → "ج.م", SAR → "ر.س", …): "⁦1,234.50⁩ ج.م".
- null, undefined or NaN show "—", meaning unknown and never 0. This is load-bearing in profitability Cost/Margin, valuation, staff drinks, till closing figures and Basira.
- `fmtMoneySigned`: "+EGP 20.00" / "−EGP 5.00" (till adjustments and variance).
- `fmtMoneyCompact` (chart axes): en-US compact, at most 1 dp: "EGP 1.2K".
- The quadrant's Y axis uses `fmtMoney(v, {maxFractionDigits: 0, currency: false})`.
- Exports: Excel money columns are numbers in pounds; CSV money columns are plain numbers equal to piastres / 100.

### 11.2 Numbers and percents
- `fmtNumber`: Intl in the app locale, Latin digits, true minus.
- `fmtPercent(ratio)`: style percent, at most 1 dp.
  - Server values on a 0-100 scale are divided by 100 before formatting: margin_pct, margin_share_pct, void_rate_pct, quadrant popularity, repricing target_pct and margin_pct, peak revenue_pct and orders_pct, margin targets in the decisions log.
  - Values used as ratios directly: loyalty rates, campaign return_rate, tax org_tax_rate, bundles margin (a wire string decimal via `rateOf`/`fmtRate`).
- `fmtShare(part, total)` = percent of part / total; "0%" when total is 0.
- `bpsLabel(bps)`: bps / 100 → "12%" or "12.5%".
- Decimals: Turns / day on the Tables page at most 2 dp. Table history "Turns a day" = x100 / 100 with exactly 1 dp. Items / order 1 dp. Avg lead time 1 dp. Peak "Avg / Day" orders 1 dp.

### 11.3 Dates and times
- The active timezone is the selected branch's zone, else the org's (fallback Africa/Cairo). All formatters use it.
- `fmtDate`: "08 Oct 2026". `fmtDateTime`: "08 Oct, 06:02 PM". `fmtTime`: "06:02 PM". All 12-hour with uppercase AM/PM; Arabic uses ص/م; Latin digits.
- `fmtHour(h)` and `fmtWireTime("19:00")`: "07:00 PM" (chart hour buckets).
- `fmtPeriod`: daily "8 Oct" (month short + day, locale order); monthly "Oct 2026".
- `fmtElapsedMs`: "0m", "42m", "1h 05m", "1d 03h". Arabic: "42 د", "1 س 05 د", LTR-isolated.
- `fmtDwell` (Tables): "—" under 1 minute, "42m", "1h", "1h 05m", with English letters in both languages.
- Local-date parameters (`localDate` = `cairoParts` in the active zone → YYYY-MM-DD) are sent by Bundles (from/to), Staff discipline (from/to) and Staff drinks (business_date = the local day of `to`; from/to). Every other report sends the ISO instants.
- `fmtBusinessDate("YYYY-MM-DD")`: the day is pinned to local noon in the active zone, then fmtDate, so it never slips a day; "—" when malformed.
- Export file-name date = the UTC date of "now" (`toISOString().slice(0,10)`).

### 11.4 Values computed in the browser (reproduce exactly)
- **Overview**:
  - AOV = round(total_revenue / total_orders), 0 when there are no orders.
  - Payment slices: value > 0, sorted desc.
  - By-category: top 10 by revenue.
  - Top items: first 10.
- **Tellers / Waiters / Branches charts**: sort by revenue desc; top 10 for tellers and waiters, all branches.
- **Tables**:
  - section list = distinct sorted sections;
  - top-revenue chart = top 12 of the filtered rows;
  - hour series filled from the first to the last hour;
  - row key = branch|section|table;
  - floor id lookup by label (single branch only).
- **Profitability**:
  - trend = (cur − prev) / prev when prev > 0;
  - Sold delta = quantity_sold − prev_quantity;
  - "below target" tint when margin_pct < target_pct;
  - export Margin % rounded to 1 dp.
- **Quadrant** (`quad:48-81`), over the whole ledger, rows with quantity_sold > 0 and margin known:
  - popularity line at 70 / n (%);
  - unit-margin line at Σmargin / Σunits;
  - dot x = units / Σunits × 100; dot y = margin / units;
  - only rows the server classed star, workhorse, challenge or dog are plotted.
- **Target editor**:
  - valid = blank, or 0 < v < 100;
  - dirty = non-empty and different from the seed;
  - two sequential PUTs.
- **Repricing**: costed = skus_considered − skus_cost_unknown.
- **Decisions**: before→after delta tone; "Measuring…" until there is an impact.
- **Financial valuation by category**: Σ value per catalog category_name (items with null value skipped), sorted desc; bar relative to the max.
- **Tax**:
  - taxable = subtotal − discount_amount;
  - VAT-registered = rate > 0 OR tax_collected > 0 OR refunded_tax > 0.
- **Legal**:
  - visible tabs = module ∩ extra cap;
  - reason wording (REP-LEG-022);
  - empty = total_count 0 and no history.
- **Loyalty**: earning = repeat_members + one_time_members; campaigns empty when none were sent.
- **Bundles**:
  - margin KPI = (revenue − cost) / revenue, only with no cost_missing row;
  - "≥ " cost floor;
  - mix share = count / slot total, sorted by count desc.
- **Staff discipline**: group by department_id in first-appearance order; the null department is "Unassigned".
- **Staff drinks**:
  - `staffDrinkMoney` (`spu:31-40`): unpriced when comp_minor is null; tillSaid shown only when it differs;
  - oneDay = local(from) == local(to).
- **Tills** (`tlib`):
  - salesStats (bill average over orders, not tills);
  - timingStats: the circular mean of times of day (unit vectors; null when they cancel; result mod 1440); average length over closed sessions with a non-negative span; the longest such session; open-now count;
  - byHour: 24 buckets in the local zone;
  - status label (open / force_closed / closed);
  - a 400 response means "range refused".
- **Basira**:
  - frame parsing (split on a blank line, keep partial frames buffered);
  - result plotting (money / 100 on axes);
  - heatmap opacity;
  - provenance string;
  - Enter-to-send only on non-touch devices.
