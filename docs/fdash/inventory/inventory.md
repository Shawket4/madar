## How to read a row

`| ID | Behaviour | API call | Gate | i18n keys | Web source |`

- **API call**: `METHOD /path operationId` — the operationId is the generated method name
  (`dashboard_api`: `api.inventory.listBranchStock(...)`). "—" = no call.
- **Gate**: what the web checks before showing/enabling the control. `nav:` = only the sidebar leaf is
  gated (the page itself is reachable by URL); `none` = shown to whoever reaches the page and the server
  decides (the backend capability that refuses is given in brackets so the mock server can 403 the
  same way). Module is `pos` for every row (D: area-wide rows).
- **i18n keys**: the web key and the en.json words (en.json wins over an inline default; see §9).
- Toasts are sonner toasts. A failed mutation always toasts `getErrorMessage(e)` (the server's words in
  the active language) and leaves the dialog open, unless a row says otherwise.
- "Invalidate inventory" = the web's `invalidateInventory()` (`lib.ts:16`): every cached query whose key
  (the request path) starts with `/inventory`, `/stocktakes`, `/purchasing` or `/reports`, awaited
  before the success toast and the dialog closing.

- **Money** (`fmtMoney`): piastres → EGP with 2 decimals, `en-US` grouping, Western digits. EN `EGP 1,234.50`, `−EGP 50.00` (true minus U+2212), signed `+EGP 20.00`; AR `⁦1,234.50⁩ ج.م` (figure LTR-isolated with U+2066/U+2069). null/undefined/NaN → "—" (unknown, never free). A figure that rounds to 0.00 has no sign. Used: costs, values, totals, net difference (signed), variance KPIs, by-reason.
- **KPI money** (`StatValue`): exact → no decimals → compact `EGP 1.2K`; the first that fits; exact in a popover when shortened.
- **Numbers** (`fmtNumber`): `Intl.NumberFormat("en-GB" or "ar-EG", {numberingSystem:"latn"})` (default max 3 fraction digits), every `-` replaced by U+2212. Differences/movements use `signDisplay: "exceptZero"` (`+2`, `−3`, `0`).
- **Unit cost** (`formatUnitCost`): piastres-per-unit ÷ 100 with exactly 6 fraction digits (`0.045680`, `33.333333`), locale grouping.
- **Units**: display after a figure via `fmtUnit` (g, kg, ml, **L** for `l`, pcs; NOT translated; unknown passes through); in selects the translated `units.*` labels (AR جم، كجم، مل، لتر، قطعة). Receive dialog's Ordered column shows the raw purchase unit code.
- **Dates**: `fmtDate` = `dd MMM yyyy` (e.g. "08 Oct 2026"); `fmtDateTime` = `dd MMM, hh:mm AM/PM` (12-hour, uppercase AM/PM in EN, ص/م in AR, Western digits); `fmtTime` = `hh:mm AM/PM`. All in the active timezone; null → "—".
- **Inputs**: EGP typed → piastres `Math.round(egp × 100)`; piastres shown in inputs as `piastres / 100` (item cost) or `toFixed(2)` (line totals). Expected date → end of the picked day (23:59:59.999) in the active timezone as a UTC ISO instant.
- **Excel**: see INV-ALL-013 (filename date = UTC `YYYY-MM-DD`).
