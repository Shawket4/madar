## How to read a row

`| ID | Behaviour (what the user does and sees) | API call | Gate | i18n keys | Web source |`

- **API call**: `METHOD /path` + operationId (the Orval hook / `dashboard_api` method name, lowerCamelCase).
  "—" = no call (client-side only).
- **Gate**: the web's own check. Capabilities are written as their keys (`orders.read` = `Cap.ordersRead`).
  `nav` = only the sidebar/command-palette entry is gated; the page itself renders for anyone who types
  the URL. `srv:` = the backend's check (from `MadarRust/src/**` handlers, mapped through
  `madar-shared/authz/spec/capabilities.toml`), which the mock server must enforce with a 403 envelope;
  the web does NOT hide the control for it. `module pos` = the page belongs to the POS module.
  "none" = shown to whoever reaches the page.
- **i18n keys**: `key` "en.json text". Where the web's inline default differs from `en.json`, the
  en.json words are given (the Flutter app syncs en.json, so those are what the user sees) and the
  inline default is noted as `inline:`. Keys missing from en.json/ar.json are listed per page in §4.
- **Toasts** are `toast.success/error` (sonner). A failed mutation always toasts `getErrorMessage(e)`
  (the server's message, already in the active language) unless a row says otherwise.
  (corrected) Not always the server's own words: see SELL-ALL-017 for the exact mapping (an uncoded 403
  reads `errors.unauthorized`, coded errors read `errors.codes.*`).
- **Invalidation names** (React Query keys are the URL path, first element):
  - `invalidateFloor` = every query whose key starts with `/floor` (`features/floor/util.ts:4`);
  - `invalidateOccupants` = starts with `/open-tickets` (`floor/util.ts:11`);
  - `invalidateBookings` = starts with `/bookings` OR `/floor` (`bookings/util.ts:55`);
  - `invalidateTills` = starts with `/tills` OR `/reports` (`tills/api.ts:78`);
  - `isPersonQuery` = starts with `/customers` OR `/loyalty/` (`customers/util.ts:70`);
  - the orders void invalidates `["/orders"]` (exact first element: the list queries, NOT
    `/orders/export`) and `["/orders/{id}"]` (`orders/void-order-dialog.tsx:44-45`).

### 1.3 Formatting and browser-side computations

- Money: integers in minor units (piastres) → `fmtMoney`: EN `EGP 1,234.50`, `−EGP 50.00` (true minus U+2212);
  AR `⁦1,234.50⁩ ج.م` (figure LTR-isolated, label after). Two decimals, Latin digits, en-US grouping.
  `null` → "—". Compact (`fmtMoneyCompact`) "EGP 1.2K". (`lib/format.ts:57-133`)
- Numbers `fmtNumber` (en-GB / ar-EG locale, Latin digits, true minus). Percent `fmtPercent` 1 decimal;
  `fmtShare(part,total)` = 0 % when total is 0. (`lib/format.ts:135-158`)
- Dates in the ACTIVE branch/org timezone (never the device zone), 12-hour clock with uppercase AM/PM,
  Latin digits: `fmtDateTime` "08 Oct, 06:02 PM"; `fmtDateTimeFull` "08 Oct 2026, 06:02 PM"; `fmtDate`
  "08 Oct 2026". (`lib/format.ts:160-199`)
- Order ref fallback: `order_ref ?? "#" + (display_number ?? order_number)` (table/sheet); the void title and
  export use `order_ref ?? "#" + order_number`.
- Staff drink: `normal = charged + comp`, `charged = line_total + Σ addon.line_total + Σ optional.price × qty`;
  add-on normal = `line_total + staff_comp_minor`; order comp = Σ `staff_comp_minor` (≥ 0). Stored totals
  are already net — never subtract again. (`orders/staff-drink-lines.ts`)
- Rewards: a line is a reward when `is_reward` or `reward_covered > 0`; total covered = Σ max(0, covered).
  (`orders/reward-lines.ts`)
- Combos: header total = Σ over parts of (line_total + Σ addon line_total). Deals total = Σ max(0, discount).
  Summary "Items at normal price" = subtotal + staff comp + deals total. (`features/combos/order-lines.ts`)
- COGS = Σ known `line_cost`; any line with `cost_missing` or null cost → prefix "≥ " on COGS and "≤ " on
  profit; profit = total − COGS; % = profit / total when total > 0.
- Ingredient cost = snapshot `cost` ?? (quantity × catalog `cost_per_unit` by `org_ingredient_id`).
- Distance = `road_distance_meters / 1000`, exactly 1 decimal + " km".
- Discount attribution: basis points / 100 → "12.5%" (integer → no decimals; else 2 decimals with a trailing
  0 removed). (`features/discounts/discount-attribution.ts:21-25`)
- Delivery channel bar = max(2 % of the largest channel revenue, this revenue) over the largest.
- Export default file name and slugs as in SELL-ORD-075; Excel date columns are real dates.

### 2.3 Formatting and browser-side computations

- Geometry in canvas units; snap grid 10; rotation step 15°; min table 24; default sizes rect 120×80,
  circle 90×90; zoom 0.1–4, step 1.25; fit padding 80; empty frame 1000×700; paste offset 20;
  history 100 steps; autosave debounce 600 ms. (`floor/util.ts:90-231`, `floor-page.tsx:63-65`)
- Rotation envelope = circle of the table's diagonal (`hypot(w,h)/2`) about its centre — used by fit,
  marquee hit-testing, align and distribute. Angles normalised to 0–359.
- Times: reservation chip `fmtTime` (branch zone, 12 h, "07:30 PM"); stay / waiting `fmtElapsedMs`
  ("0m", "42m", "1h 05m", "1d 03h"; Arabic "42 د", "1 س 05 د", LTR-isolated).
- Money `fmtMoney` (minor units). Turns `turns_per_day_x100/100` with exactly one decimal.
- Capacity: seats = Σ visible seats; taken = Σ seats of tables seated or occupied; free = seats − taken;
  needs clearing = count of dirty tables nobody occupies.
- Suggested label = "T" + (max numeric suffix of labels matching `^T(\d+)$`, case-insensitive) + 1.
- Unique paste label: strip a trailing " (n)", then the first free of stem, "stem (2)" … "stem (998)".

### 3.3 Formatting and browser-side computations

- The booking day is a plain calendar date `YYYY-MM-DD` in the branch timezone (`serviceToday`, rolls over
  at local midnight, follows DST); previous/next day is calendar arithmetic. (`bookings/util.ts:62-85`;
  tests `util.test.ts:15-34`, `:87-92`)
- A custom time "HH:MM" on a day → the UTC instant of that wall clock in the branch zone (`localInstant`);
  an instant → "HH:MM" wall clock (`localHHMM`). (`util.ts:88-99`)
- Times shown with `fmtTime` (12 h, "07:30 PM", branch zone, Latin digits); hour ticks with `fmtHour`
  ("06:00 PM"). Export cells are date-times.
- Late = confirmed AND start < now; Due/held = confirmed AND `held_from` ≤ now (Late wins). Active =
  confirmed or seated. Covers = Σ party of seated + completed.
- Timeline: minutes from the date's local midnight; left % = (max(start, open) − open) / span; width % =
  max((min(end, close) − start) / span, 1.5), clamped to the row.
- Phone: canonical = E.164 digits without "+" (`201001234567`); Arabic-Indic digits converted; "00…" and
  leading "0" handled; Egyptian mobiles must be 12 digits. Display `+20 100 123 4567` (LTR); input form
  `01001234567`. Shared vectors `phone_vectors.json`. (`lib/phone.ts`)

- **Web files read**: `routes/_app/tills.tsx`, `routes/_app/shifts.tsx`; `features/tills/tills-page.tsx`,
  `api.ts`, `util.ts`, `redirect.ts`, `till-badges.tsx`, `open-till-dialog.tsx`, `close-till-dialog.tsx`,

- **Capabilities**: nav `till.read`. In-page: "Force close" needs `till.force_close`; "Delete" needs
  `till.delete`; the report's "Spot reports viewed" section needs `till.read`. "Open till", "Cash movement"
  and "Close till" are offered by situation (a branch is selected and you have no open till here / it is
  YOUR open till), not by capability; the server checks `till.open` (open) and `till.operate`
  (close-preview, close, cash movement). Server reads: list/open/report `till.read` (plain `till.read`
  answers only the caller's own tills; every drawer needs `till.read.branch`); current `till.read.branch`
  or `till.read`; open-bills notice `tickets.read`.

  /tills/branches/{branch_id}/open), `getOpenBillsNotice` (GET /tills/branches/{branch_id}/open-bills-notice),

- **Invalidation**: open, close, cash movement, force close, delete → `invalidateTills` (all `/tills…` and

### 4.3 Formatting and browser-side computations

- Money in minor units; amounts typed in pounds are sent as `Math.round(pounds × 100)` (`egpToPiastres`);
  the open dialog pre-fills `suggested / 100`. Cash out is sent negative.
- `fmtMoneySigned` for discrepancy and cash movements ("+EGP 20.00" / "−EGP 50.00"); zero shows "EGP 0.00".
- Elapsed "open for" = `fmtDuration(opened_at)` (now − opened, "42m", "1h 05m", "1d 03h"; Arabic units LTR).
- Date-times `fmtDateTime` in the branch zone.
- Flagged = `opened_while_another_open || reconciliation_status == "disagreed"`.
- Stock used: per `inventory_item_id:unit`, used = Σ quantity_deducted (sales positive, void/refund
  restocks negative), returned = Σ |negative rows|; quantities rounded to 3 decimals + unit (`g`, `kg`,
  `ml`, `L`, `pcs`).
- Order range: `<device_code>-<first> – <device_code>-<last>` (no code → plain numbers).
- The "Today" filter uses the DEVICE's local midnight (not the branch zone) — reproduce as is.
- Teller/Device filter options are derived from the currently loaded rows (distinct ids).

### 5.3 Formatting and browser-side computations

- Phone display `formatPhoneDisplay` (`+20 100 123 4567`, else `+<digits>`, else as stored), always LTR;
  form pre-fill as stored; validation by the shared rule (SELL-BKG-046 / §3.3). The merge picker shows the
  raw stored phone (no formatting).
- Money `fmtMoney` (minor units); dates `fmtDate` "08 Oct 2026", date-times `fmtDateTime` (branch zone).
- Birthday `Intl` `{day: numeric, month: long}` in the UI language for 2024 (leap year), UTC.
- Balance shown = `visits_balance` when mode is visits else `points_balance` (0 when missing), only for
  members and only when the mode is known. Unit words are plural-aware (`loyalty.unitPoints` /
  `loyalty.unitOrders`, Arabic six forms).
- Load-more window: limit = min(50 × pages, 500); "has more" = shown ≥ limit and limit < 500.
- Export walks offset += rows received, stops on an empty page or once `total` is reached; > 50,000 → refuse.
- Ledger amount: "+n" / "−n" (U+2212) / "0".
- Address line: place, "Unit n", "Floor n", street line, landmark — trimmed, blanks dropped, joined " · ".
