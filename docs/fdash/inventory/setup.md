## How to read a row

`| id | behaviour | API call | gate | i18n keys | web source |`

- **id**: `SET-<PAGE>-NNN`. Page codes: `SHL` settings shell and area-wide, `APP` appearance, `BRD` brand, `LNK` links,
  `DLV` delivery, `DZN` delivery zones, `BKG` bookings, `LOY` loyalty, `QR` QR codes, `CMB` combos and deals,
  `PAY` payment methods, `SPL` staff drinks, `KST` kitchen stations, `KRT` order routing, `INT` integrations,
  `WA` WhatsApp. One driven test per row.
- **API call**: `METHOD path operationName` (operationName = the Orval name = the `dashboard_api` method name).
  "—" = no request.
- **gate**: capability (`Cap.*`, any-of), module (`pos`), `platform` (super admin, `authz.platform`), or "none"
  (whoever reaches the page; the server decides).
- **i18n keys**: the keys the row shows. Text in quotes is what the user sees in English; it is the **en.json
  value** (where the web's inline default differs, the en.json value wins and is the one quoted; see §F).
- A failed mutation always toasts the server's words (`getErrorMessage(e)`, already in the active language)
  unless the row says otherwise.
- Strings with `{{x}}` are i18next interpolations; `_one/_other…` keys are plurals (Arabic uses all six forms).

## A. Formatting rules and browser-side computations

Reproduce these exactly (the Flutter port computes the same in Dart from `dashboard_core` formatters):

- **Money** (`lib/format.ts` `fmtMoney`): the wire is piastres (minor units); shown as EGP with 2 decimals, grouped thousands,
  Western digits in both languages. EN `EGP 1,234.50`; AR `⁦1,234.50⁩ ج.م` (figure LTR-isolated with U+2066/U+2069, label after).
  Negative uses a true minus U+2212. `null` → "—". Used by: discount labels (Delivery), zone fee, reward/earning picker labels
  ("name · price"), loyalty overview (liability, value given away, top rewards), members Total spent.
- **Money in forms**: EGP on screen, piastres on the wire — `egpToPiastres(x) = round(x × 100)`, `piastresToEgp(p) = p / 100`.
  Delivery fees, zone fee, loyalty earn rate (`earn_piastres_per_point`).
- **Numbers** (`fmtNumber`): locale `en`/`ar` formatter with `numberingSystem: latn` (Western digits), minus → U+2212. Zone distance:
  `meters / 1000` with `maximumFractionDigits: 1` + " km". Stat cards (members, outstanding, redemptions) use it.
- **Dates/times**: `fmtDate` = `dd MMM yyyy` in the active timezone (branch/org tz), Western digits; `fmtDateTime` =
  `dd MMM, hh:mm AM/PM` on the 12-hour clock (Arabic `م/ص`), active timezone. Used by: ledger When, member Joined, members
  Joined/Last visit, integrations Last used. Time fields (delivery windows) store `HH:MM:SS` (24-hour wire) and display on the
  12-hour clock; booking hours are raw 24-hour `HH:MM` text inputs.
- **Weekday names** (booking hours): `Intl.DateTimeFormat(ar ? "ar-EG" : "en-GB", {weekday: "long", timeZone: "UTC"})` of
  `2024-01-07 + dow` (dow 0 = Sunday … 6 = Saturday); rows run Sunday → Saturday.
- **Excel exports** (`lib/excel.ts`): file name `<base>-<UTC YYYY-MM-DD>.xlsx`; org logo in the sheet header; a sheet has a name, a
  title and an optional subtitle; column types text / integer / money (piastres → EGP) / date. Exports that walk pages send
  `X-Madar-Export: 1`. Files: `Madar-PaymentMethods`, `Madar-Order-Routing`, `Madar-Loyalty-Members`.
- **QR download** file: `qr-<short_code>.svg` when the data URL is `data:image/svg…`, else `.png`.
- **Zone numbering**: sort by `max_road_distance_meters` ascending, number 1…n; new-zone defaults: name placeholder
  `"<Zone> " + (count + 1)`, distance `max(existing km) + 1` or 1; km → m `round(km × 1000)`.
- **Delivery discount label**: `<getTranslatedName(discount)> · <value>%` for `dtype == "percentage"`, else `· fmtMoney(value)`.
- **Translated names** (`getTranslatedName`): Arabic UI and `name_translations.ar` is a string → it; else `name`. Payment-method label:
  `label_translations[lang] || .en || .ar || name`.
- **Combos margin**: form percent ↔ wire rate string: `percentToRate("55") = "0.5500"` (`(round(n × 100) / 10000).toFixed(4)`),
  blank → null; `rateToPercent("0.55") = "55"` (`round(r × 10000) / 100`).
- **Loyalty units**: `currencyLabel(mode, count)` = `loyalty.unitOrders` (stamps/visits) or `loyalty.unitPoints` with i18next plural
  `count` (default 2 when absent). Ledger amount `+n` / `−n` (U+2212) / `0`. Reward-row problems and the "dirty" rule (§7 rows 041/045,
  051). Birthday preview debounce 400 ms. `inherited` = branch scope AND response `branch_id` ≠ asked branch (same for staff drinks).
