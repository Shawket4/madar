# Admin / Organizations (`/orgs`): differences from the web

One line per difference: what the web does, what Flutter does, why. Rows marked "question" port
the web's behaviour as it is and ask the owner whether it is intended.

| Row | Web | Flutter | Why |
|---|---|---|---|
| ADM-ORG-042, ADM-APP-127 logo errors | A failed logo upload or removal shows the thrown error's raw text under the picker: axios's English "Request failed with status code 403", in both languages. | The same place shows the `getErrorMessage` words in the active language ("You don't have permission to perform this action."). | Raw transport errors shown to people are a web bug to port the intent of (SPEC 6.3). Pinned by `org_dialog_test` "ADM-ORG-042 a refused upload…". **Fixed on the web in v1.4.27.** |
| ADM-ORG-021, 040, 045, 055, 057 server sentences in Arabic | `getErrorMessage` shows the backend's English sentence (kind prefix stripped) in the Arabic UI too, e.g. "Slug 'x' is already taken" under Slug or in a toast. | In Arabic, an English server sentence is replaced by the Arabic words for its status (`errors.conflict`, `errors.validation`, `errors.notFound`, …); coded refusals and uncoded 403/429 read as on the web. In real mode the core already words refusals in the active language and those pass through unchanged. English is unchanged. | English inside the Arabic UI is a web bug (SPEC 6.3); this is the core's own rule for the same sentences. Pinned by `provision_wizard_test` "ADM-ORG-040 Arabic…" and `orgs_logic_test`. **Fixed on the web in v1.4.27.** |
| ADM-ORG-026, 042 drag and drop | The uploader also takes a file dropped onto it. | Tap to pick through `FileGateway.pickImage` (the kit's uploader); there is no drop target. | Platform: no drag-and-drop source on the phone/tablet targets. |
| ADM-ORG-031, 046, 048 number inputs | `<input type="number" step="0.1">` with browser spin arrows. | A text field with the decimal keyboard that takes Latin or Arabic digits and one decimal mark; the same 0..100 check and words. | Platform: no spin control; Arabic digits are read as the web's `z.coerce.number()` reads Latin ones. |
| ADM-ORG-059 question: untrimmed editor | The edit dialog does not trim Name, Slug or Currency: a space-only value passes the client check and is sent. | Ported as is (a space-only name is sent). | Unsure whether this is intended; the wizard trims the same fields. Owner question. |
| ADM-ORG-059 question: wizard email | The wizard checks Email as typed: a leading or trailing space reads "Enter a valid email" (the request would have trimmed it). | Ported as is. | Unsure whether intended. Owner question. |
| ADM-ORG-057 question: Arabic-only names | An Arabic-only Organization Name slugifies to an empty Slug, so step 1 stops on "This field is required" under Slug until a Latin slug is typed. | Ported as is. | Product rule of the slug (it is a web address); the empty field is the hint. Owner question whether a transliterated suggestion is wanted. |

| ADM-ORG-004 shell contract / question: deep link by a non-platform user | Anyone who types /orgs sees the page frame; the list call is refused (403) and the table shows "You don't have permission…" with Retry, zero stats, Export off and New still visible. | The route is platform-only (the shell's contract): anyone else gets the shell's Restricted page and no /orgs call is made; the mock still refuses every /orgs call. | Pages the nav hides are Restricted. Question for the owner: is Restricted wanted over the web's refused frame? Pinned by orgs_page_test "ADM-ORG-004 (divergence)…". |

| ADM-ORG-040 English conflict words | `conflictTarget` puts the server's `error` under Slug or Email with its prefix: "Conflict: Slug 'x' is already taken". | The same sentence without the "Conflict: " prefix, as every other refusal on the page is worded (`orgErrorWords`). | The kind prefix is transport noise; the web's own toasts drop it via `getErrorMessage`. |
| ADM-ORG-058 open edit dialog re-fill | The dialog fills once per org id when it opens; a refetch while open never re-fills it, so Save sends the values from when it opened. | Until the person edits, a refresh re-fills the dialog with the newer row; after the first edit it never re-fills. | Owner rule: a form seeded from cached data re-seeds until edited. |
| ADM-ORG-003 the shared /orgs entry | The page and the org picker share one `/orgs` query; opening the page refetches only if older than 30 s. | The page forwards to core's `orgsProvider` (one entry, one refetch per save); its first open or a stale reopen refetches unless already loading. | Core's `orgsProvider` keeps no fetch time, so within 30 s of the picker's read Flutter asks once more. Core candidate: webCache on orgsProvider. |
