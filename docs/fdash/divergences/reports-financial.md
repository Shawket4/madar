# Reports / Financial (`/reports/financial`): differences from the web

One line per difference: what the web does, what Flutter does, why. Rows marked "question" port
the web's behaviour as it is and ask the owner whether it is intended.

| Row | Web | Flutter | Why |
|---|---|---|---|
| REP-FIN-040 partial save | Org PUT succeeds, branch PUT fails: nothing is invalidated, so the trigger and ledger keep the old target while the org default is in fact saved. | Same toast and the popover stays open, but `/insights` is refreshed whenever any PUT went through, so what is saved is what is shown. Pinned by "REP-FIN-040 (divergence) …". | Stale figures after a save are a web bug (SPEC 6.3). |
| REP-FIN-072 scope on Fix / Adjust prices | Navigating without search params clears the URL scope: the branch falls back to All branches and the period to Last 30 days. | The scope is app state, not URL state, so it survives the navigation. Pinned by "REP-FIN-072 (divergence) …". | Losing the person's scope is a web bug; the intent is "go fix it". |
| REP-ALL-024 Channel tooltip | The bar tooltip prints the raw data key "revenue" (English in both languages) before the amount. | The translated "Revenue". | English in the Arabic UI (SPEC 6.3). |
| REP-FIN-002 / REP-ALL-030 rights loading | While the person's rights are unknown the page renders with no tabs and the Menu profitability body, and the ledger IS requested. | Nothing is rendered (an error with Retry if the rights cannot be read), as the shell's own page gate and Operations do (shell divergence SH-10); no request goes out before the rights are known. | Consistency with the shell gate; no flash of a page the person may not open. |
| REP-FIN-057 axis labels on a phone | `interval={2}`: every 3rd hour label whatever the width, so on a phone the labels overprint each other. | Every 3rd label, thinned further when the measured labels would collide on a narrow plot (daily/monthly labels are thinned the same way, as Recharts does by itself). | Overprinted text is a defect on the phone layout. |
| REP-FIN-069 suggestion badge | The `ArrowRight` glyph is not mirrored in Arabic. | Mirrored (`arrow-left` in RTL). | Direction rule (SPEC 2). |
| REP-FIN-051 status column (kit) | The header is visually hidden ("Status", `sr-only`); the phone card labels the check "Status". | `DashColumn` has no visually-hidden header, so the header is empty and the phone card shows the check without a label; the check itself carries the "Measurement complete" label. | Kit gap (kit candidate: a hidden-header column). |
| REP-FIN-038 target fields | `<input type="number" min=1 max=99 step=1>` with the browser's spinner. | A text field with the decimal keyboard and a number-characters filter; the same validation (empty, or 0 < v < 100) and the same red edge. | Platform: no number spinner in the kit. |
| REP-FIN-043/044 quadrant (kit) | Recharts scatter with `ReferenceLine`s and an HTML tooltip. | fl_chart scatter with the two dashed split lines painted over the plot and a painted tooltip with the same lines in the same order (`finQuadrantTip`). | Kit has no scatter chart (kit candidate). |
| REP-FIN-055…062 charts (kit) | Recharts charts: plot LTR in both languages, rich tooltips. | A local `FinChart` (LTR plot, a tooltip-lines builder), because the kit's charts mirror in Arabic and print one "label value" per series. | Kit gap (kit candidate: an LTR option and a tooltip builder on `DashBarChart` / `DashLineChart`). |
| REP-FIN-037 target editor re-seed | Re-fills both fields on every targets refresh, wiping anything typed. | Re-fills each field only until the person types in it; an untouched field never sends an old value. | Brief rule for forms seeded from cached data; avoids sending stale or wiping typed values. |
| REP-FIN-025/042/046/053/063/064/067/068/069 failed background refresh | A failed background refresh replaces the shown data with the error. | Data already on screen stays; the error with Retry shows only when there is nothing to show. | Core loading/error rule (`failedFirst`). |
