# Team / Payroll (incl. the money sheets): divergences from the web

| Row | Web | Flutter | Why |
|---|---|---|---|
| TEAM-PAY-036 | "Download PDF" opens a print window with the payslip's HTML and the browser's print dialog; a blocked pop-up toasts `dawam.popupBlocked`. | Builds the same payslip (company, Payslip, Employee, Period, every signed line, waived lines struck with their note, Net, carry line) as an A4 PDF in the reader's language and direction, saved through the file gateway (`payslip-<start>-<name>.pdf`). A failure toasts the error's words; there is no pop-up to block. | No browser print window in the app; the inventory row asks for a PDF via FileGateway. |
| TEAM-PAY-020 | Deductions and Advance cells are `fmtMoney(-x)`: for a zero amount JavaScript formats negative zero as "-EGP 0.00". | A zero reads "EGP 0.00"; a real amount still reads "−EGP 21.63". | Web bug (a minus sign on nothing). |
| TEAM-MNY-013/020/038/039 | Number and money fields settle on blur, and pressing Save blurs the field first, so a typed figure is always the one validated and sent. | Pressing Save settles the focused field before validating (a tap on a button does not take focus on touch platforms). Same outcome as the web. | Port of the intent; without it a typed "30" installments would be ignored and the last good value saved. Kit candidate: `DashFormField`-level settle-on-validate. |
| TEAM-ALL-009 | Focus refetch refetches each stale (≥30 s) active query of the page. | On app resume after ≥30 s since the page's data landed, every mounted `/staff` read the page shows is refetched (the Refresh button's set); sooner does nothing. | After 30 s every read of the page is stale, so the sets are the same. |
| TEAM-ALL-022 | `onError` of the query cache toasts a failed background refresh once per failure. | Each payroll read subscribes once (`PayrollRefreshListener`, `listenManual`) rather than in `build`, so a rebuild 30 s after the last answer does not refetch the read (a new `ref.listen` in build is a new listener, and `webCache` refetches stale data for a new listener). | Avoids requests the web never makes. |
