# Admin / Roles & Permissions (`/access/roles`): differences from the web

One line per difference: what the web does, what Flutter does, why. Rows marked "question" port
the web's behaviour as it is and ask the owner whether it is intended.

| Row | Web | Flutter | Why |
|---|---|---|---|
| prefetch (ADM-ROL-004, 019) | `prefetchRoute('/access/roles')` warms the Users list (`listUsers({org_id})`), which this page never reads. | Warms what the page reads on mount: the roles (`/authz/roles`) and the policy (`/authz/policy`). The policy is warmed even for someone who may only see roles (the prefetch hook does not know the person's capabilities); its read is open to any member, so this costs one unused request, never a refusal. | Warming a read the page never makes is a web bug (a copy of the Users case); the intent is that pointing at the page makes it open from the cache. Pinned by `roles_prefetch_test` and `roles_intent_test` "ADM-ROL-004/019 …". |
| ADM-ROL-004 permissions loading | While the person's permissions load, the disabled roles query has no data and the list shows "No roles yet". | The five-row skeleton until the permissions are known; still nothing is asked for the roles until they say so. | A false "No roles yet" flash is a defect (SPEC 6.1: never flash an empty state during a load). Pinned by "ADM-ROL-004 (divergence) …". |
| ADM-ROL-014 switch name | The switch's `aria-label` is the capability key (`branches.edit`). | The switch is named by the capability's words in the active language. | A machine key read aloud to people is a defect; the row's visible words are the evident label. Pinned by "ADM-ROL-014 (divergence) …". |
| ADM-ROL-017 name messages | zod's own English messages ("Too small: expected string to have >=1 characters", "Too big: …") show in both languages. | The same English words; in Arabic, their Arabic translation (supplement `access.roleNameMin` / `access.roleNameMax`). | English inside the Arabic UI is a web bug (SPEC 6.3). Pinned by "ADM-ROL-017 Arabic …". |
| ADM-ROL-021, 022 row while saving | The Hidden / Ask a manager control looks enabled while its row saves; taps are ignored. | The control is visibly disabled until the save (and the refetch) lands. | A control that silently ignores a tap is a defect (SPEC 6.1). Pinned by "ADM-ROL-021/022 (divergence) …". |
| ADM-ROL-022 failed policy read | A failed `GET /authz/policy` shows every row as "Hidden", whatever the business really chose. | The card shows the server's words and Retry, which asks again for the policy only. | Showing a guess as the saved setting is a defect (a failed load must never look like data; SPEC 6.1). Pinned by "ADM-ROL-022 (divergence) …". |
| ADM-ROL-024 Start from | Changing "Works like" keeps a "Start from" role of another kind: the select shows blank and the role is still sent as `copy_from`. | Changing the kind drops a "Start from" role of another kind back to "The usual defaults"; one of the same kind stays. | Sending a hidden choice the select no longer shows is a web bug; the options list only roles of the chosen kind, so that is the intent. Pinned by "ADM-ROL-024 (divergence) …". |
