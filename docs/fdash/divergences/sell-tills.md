# Divergences: sell / tills (`/tills`)

| Row | Web | Flutter | Why |
|---|---|---|---|
| SELL-TIL-060 | "Open now" shows the "No open till" empty state while its read is still loading and after it fails (`tills={openNow.data ?? []}`). | A skeleton while loading; after a failure an error state with the server's words and a Retry that re-reads only the open tills. Pinned by `SELL-TIL-060 (divergence) …` tests. | A failed or unfinished load shown as "nobody is selling" is a bug (SELL-ALL-010: a failed load is never shown as empty). | SELL-TIL-061 | When the close-preview read fails, the dialog keeps its skeleton forever (no error, no Retry, no buttons). | The dialog shows the refusal / error words (`getErrorMessage`) and a Retry. Pinned by `SELL-TIL-061 (divergence) a refused close preview …`. | A form that can never load and never says why is a dead end; port the intent. |
| SELL-TIL-061 | A preview refetch (a `till.*` event while the dialog is open) resets the form: the typed count, notes and payment checks are lost. | What was typed is kept; rows follow the refetched methods (a method that disappears drops its row, a new one is added as Checked). Pinned by `SELL-TIL-061 (divergence) a refetched preview keeps what was typed`. | A lost count mid-close is a lost save. |
| SELL-TIL-022 | Hovering anywhere on a row prefetches the report (`onRowPrefetch`). | Hovering any cell of the row prefetches it (the kit's `DashDataTable` has no row-hover hook; each cell is wrapped).
