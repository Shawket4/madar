# Catalog / Menu Studio (`/menu/items/:itemId`): differences from the web

One line per difference: what the web does, what Flutter does, why. Rows marked "question" port
the web's behaviour as it is and ask the owner whether it is intended.

| Row | Web | Flutter | Why |
|---|---|---|---|
| MENU-STUDIO-020, 087 clearing a deduction | "Clear" empties the option's ingredient and Save sends `recipe: null`; the server reads `null` as "leave the lines as they are", so the cleared deduction is still there after the refetch (a save that silently does nothing). | An option with no ingredient sends `recipe: []`, which clears it; an ingredient with no usable quantity still sends `null` (unchanged), as the web. Pinned by "MENU-STUDIO-086/087 deducts: pick, quantity, cost, clear" and the `optionsPayload` unit test. | A lost edit is a web bug (SPEC 6.3); the intent of "Clear" is "no deduction". |
| MENU-STUDIO-003 a failed refetch | `studioQ.isError \|\| !studio` shows the error page whenever a refetch fails, even with the item already on screen (and unsaved edits in the drafts). | The error page shows only when there is no data yet; a failed background refetch keeps the page and its drafts. | Throwing away a page of edits on a background failure is a web bug; the brief's rule: error state only when failed with no data. |
| MENU-STUDIO-070 a failed step library | The picker shows "The animation library is empty." when the presets read failed (or was refused). | The picker shows the failure's words and Retry; "empty" only for a real empty library. Pinned by "MENU-STUDIO-070 a failed library: the reason and Retry, never "empty"". | A failure shown as "nothing here" is a web bug (SPEC 6.1/6.3). |
| MENU-STUDIO-092 a failed combos read | `!combosQ.isLoading && combos.length === 0` shows "No combos yet. Create one first…" when the combos read failed. | The note shows only for a real empty list; on a failure the Combo select stays (with "Not offered"). | Same rule as above. |
| MENU-STUDIO-002 loading title | The header's title is a 224 px skeleton beside the back button. | The skeleton sits under the header row (the kit's `DashPageScaffold` title is a string). | Kit: no title widget slot (kit candidate). |
| MENU-STUDIO-044 "Copy from ▸" | A hover submenu of the column's ⋯ menu. | "Copy from" (with a "›" hint) closes the menu and opens a second menu of the other sizes on the same ⋯ button. | Kit: `DashMenu` has no submenus (kit candidate). |
| MENU-STUDIO-013 leave guard | `beforeunload` asks "Leave site?" when the browser tab closes with unsaved edits; in-app navigation is not guarded. | No guard (no in-app guard either, as the web). Pinned by "MENU-STUDIO-013 no in-app guard: Back leaves with edits". | No window-close hook in the app shell; the inventory says "desktop window close only, if at all". |
| MENU-STUDIO-071 animations and reduced motion | The library tiles play their animation (always); row frames are still. | MENU-STUDIO-102, 106, 107 Arabic figures | Chip prices are `" +" + figure`, deduction lines `name · qty unit`. | Same words; the signed figure is one LTR unit ("+25") and quantities are isolated, so the sign and the unit stay on the right side of the number in Arabic. | Bidi rendering only (Flutter isolates figures; the browser joins them to the Latin run). |
| MENU-STUDIO-065, 067, 018 question: preset notes | The server answers a preset step's note as the step's own note, else the library's (`step_note.or(note)`); the studio seeds the note box from it, so every preset step's note box starts filled with the library's wording, and the next Save writes that wording as this drink's own note. | Ported as is (the box shows the library's note; Save sends it). Pinned by "MENU-STUDIO-018 steps: preset and written payloads". | Unsure whether intended: after one save the step no longer follows a later change of the library's note. Owner question. |
| MENU-STUDIO-113 question: raw labels | The preview lists the stored size labels ("one_size" for a one-price item) and the raw group and option names, also in Arabic. | Ported as is. | Inventory row; looks unintended next to the grid's "Price". Owner question. |
